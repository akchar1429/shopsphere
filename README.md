# 🛍️ ShopSphere — E-Commerce Product Catalog

A modern, responsive e-commerce product catalog web application built using React and Vite. ShopSphere provides an interactive shopping experience with product browsing, search, category filtering, sorting, and a shopping cart that persists using browser LocalStorage.

## 🌐 Live Demo

**Live Website:** https://shopsphere-swart-eta.vercel.app/

**GitHub Repository:** https://github.com/akchar1429/shopsphere

## 📌 Project Overview

ShopSphere is a frontend web development capstone project designed to demonstrate modern React development, component-based architecture, state management, responsive user interface design, and client-side data persistence.

The application allows users to explore products, search for items, filter products by category, sort products, and manage their shopping cart.

## ✨ Features

* 🛍️ Product catalog with product cards
* 🔍 Search products by name
* 🗂️ Filter products by category
* ↕️ Sort products by price and rating
* 🛒 Add and remove products from the cart
* ➕ Increase or decrease product quantities
* 💾 Save cart information using LocalStorage
* 📱 Responsive design for desktop, tablet, and mobile screens
* 🔔 Interactive notifications
* 🎨 Modern user interface
* 🌐 Live deployment using Vercel

## ⚙️ Installation and Setup

### Prerequisites

Install Node.js and npm before running the application locally.

### 1. Clone the repository

```bash
git clone https://github.com/akchar1429/shopsphere.git
```

### 2. Navigate to the project directory

```bash
cd shopsphere
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### 5. Build for production

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.

## 🛒 How to Use

1. Open the ShopSphere website.
2. Browse the available products.
3. Search for products using the search field.
4. Filter products by category.
